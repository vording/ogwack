# 大喜利道場(ChatGPT の GPT 版)

ChatGPT の「GPT」として大喜利ゲームを作るための設定です。作成した GPT のリンクを送れば、友達は自分の ChatGPT でそのまま遊べます。

## 作り方(ChatGPT 上で操作)

1. ChatGPT を開き、左メニューの「GPT」→「+ 作成する」を押す(GPT の作成には有料プランが必要です)。
2. 「構成(Configure)」タブを開いて、下の内容を入れる。
   - **名前**:大喜利道場
   - **説明**:お題に答えると、先輩芸人風の審査員が講評して座布団をくれる大喜利ゲーム。ひとりでも、友達との対戦でも。
   - **指示(Instructions)**:`instructions.md` の中身をまるごと貼り付け
   - **会話のきっかけ**:
     - ひとりで挑戦する
     - みんなで対戦する
     - すぐ1問出して
     - ルールを教えて
   - **機能**:ウェブ検索・画像生成・コードインタープリターはすべてオフでOK
3. 右上の「作成する」→ 公開範囲を **「リンクを知っている人」** にして保存する。
4. 表示されたリンクを友達に送る。

## 遊び方

- 「ひとりで挑戦」:5問勝負。座布団0〜3枚で採点され、合計で番付(見習い→前座→二ツ目→真打→名人)が決まる。
- 「みんなで対戦」:1つのメッセージに `たろう:回答` `はなこ:回答` のように名前付きで書くと、全員まとめて審査して毎問 MVP を発表する。
- 合言葉:「チェンジ」(お題を変える)、「もう一回」(答え直し)、「次」、「結果」。
